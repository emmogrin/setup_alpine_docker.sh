# Alpine Docker Setup

This repository provides a one-click setup script to install Alpine Linux on QEMU and install Docker. Follow the steps below to run the script.

## Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/emmogrin/setup_alpine_docker.sh.git
   cd setup_alpine_docker.sh
   2. Make the script executable:

chmod +x setup_alpine_docker.sh


3. Run the script:

./setup_alpine_docker.sh

The script will download Alpine, create a disk image, and set up Docker in a QEMU virtual machine.
